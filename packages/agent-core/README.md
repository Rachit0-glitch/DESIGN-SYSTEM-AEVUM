# @aevum/agent-core

Phase 13 canonical contracts for immutable agent goals, sessions, runs, observations, diagnostics, budgets, approvals,
verification outcomes, and structured audit records.

This package stores no hidden model reasoning and never reads or mutates canonical project state. Planning, context
assembly, and MCP execution belong to their dedicated packages. See `docs/02_SYSTEM_ARCHITECTURE.md` and
`docs/08_MCP_SPECIFICATION.md` for the mandatory Agent to MCP to Command Engine boundary.
