# @aevum/lighting

Phase 20 lighting and environment domain package for the AEVUM AI Reconstruction Engine.

It provides deterministic reference-light analysis, canonical lighting-rig construction, real-time/offline/mobile delivery profiles, runtime resolution, shadow and reflection validation, and bounded correction proposals. Persistent writes remain owned by the Command Engine; Blender remains an execution backend.

See `docs/07_3D_ENGINE_AND_CINEMATICS.md` and `docs/11_ROADMAP_AND_STATUS.md`.
